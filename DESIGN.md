# Website design context
Audience: executive recruiters and technical hiring managers reviewing Mahmoud Salama's work.
Preserve the established cream, navy, teal and sticky-note identity. Existing page CSS remains canonical; the casebook uses the same palette and restrained editorial hierarchy.
Runtime owners: executive-canvas.css and site-nav.css for primary pages; delivery-casebook.css for the casebook's scoped layout. Colors: paper #fbfaf4, ink #10263b, teal #086c75, line #dce5e8, gold #e4be57. Body: Segoe UI/Arial fallback; existing display faces retained.
Accessible navigation, visible focus, readable text, 2-column cases collapsing to one below 700px, reduced motion and natural document scrolling. No public interview scripts or confidential evidence.
Content: distinguish current users from cumulative trainees, a 54-person organization from engineers, personal development from team leadership, and institutional awards from personal awards.
