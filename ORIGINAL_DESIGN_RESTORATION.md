# Original Design Restoration

This package restores the original Mahmoud Salama portfolio design and brand palette.

Preserved exactly:
- Original page structure and layout
- Original yellow, pink, cyan, purple, navy, black, and white palette
- Original typography, background artwork, buttons, cards, navigation, and animations
- Original desktop and mobile visual identity

Functional fixes retained without redesign:
- GitHub Pages-compatible relative asset paths
- `.nojekyll` support
- Conditional Vercel Analytics loading
- GitHub Pages contact fallback
- Official MedIQ logo supplied by the user
- Existing CV-aligned content, mobile fixes, experience-title styling, and button-animation fixes
