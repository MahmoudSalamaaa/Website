# Mahmoud Salama Executive Portfolio

Production-ready static portfolio for Vercel.

## Main pages

- `/` — executive profile and selected work
- `/portfolio.html` — complete project archive
- `/card.html` — digital business card
- `/resume.html` — browser CV view
- `/api/contact` — secure server-side contact endpoint

## Deployment

Replace the current repository contents with this folder, then deploy through the existing Vercel project. See `DEPLOYMENT.md` for the required contact-form environment variables.
