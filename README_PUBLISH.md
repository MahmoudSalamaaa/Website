## Publish notes
1. Upload the contents preserving folder paths.
2. Verify `/sitemap.xml` and submit it to Google Search Console.
3. Configure an analytics provider only if desired. `assets/analytics.js` supports `gtag` or `plausible` if you add the provider script.
4. Record the video from `media/video-intro-script.txt`; add it later only when you have a genuine recording.
5. Add testimonials only after consent using `media/recommendations.example.json`; no quote was fabricated.
6. Existing Drive CV links are preserved.
