# Mahmoud Salama — Wave 6 Executive Intelligence & Influence OS

This package is additive. Copy only the `executive-os/` folder into the repository root.

Protected public files intentionally NOT included:
- root `index.html`
- root `site-main.css`
- root `card.html`

Entry point after deployment: `/executive-os/`

Wave 6 uses localStorage for trackers and can read known Wave 5 tracker keys when all folders are served from the same origin. It does not upload tracker data to an external service.

All public-career claims inside the packaged evidence data follow the existing evidence-first policy. The probability and digital-twin modules are transparent planning heuristics, not hiring predictions.
