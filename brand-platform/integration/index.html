Visual Safety

Protect the surfaces that already work

Wave 3 is deliberately designed around a boundary: internal products can evolve substantially, while the main homepage and Digital Card should remain visually stable.

Frozen visual boundary

Main website `/`

Preserve the current section order, hero composition, sidebar/navigation behavior, existing project/gallery layout, animation identity and overall spacing rhythm. Any future branding change should be wording, metadata or an isolated existing-style link — not a new standalone design language.

Frozen visual boundary

Digital Card `card.html`

Preserve the card composition, portrait treatment, dark/light experience, action layout and contact-grid structure. Identity updates should be limited to copy, metadata, destinations or token-level adjustments only when intentionally requested.

Safe homepage integration

Prefer links, not sections

Expose Wave 3 through an existing Projects / Portfolio / Executive Portfolio pattern or a small existing-style CTA. Do not append a visually unrelated “Brand Platform” block to the homepage.

Safe internal integration

Use Brand System v3 freely

Executive Platform, labs, frameworks, research, perspectives, media and career tools may use the new internal identity and components.
