1. Think in capabilities

Compute

EC2 · Auto Scaling · ELB · Lambda · Fargate
Choose by control vs operational burden; use multiple AZs when availability requires it.

اختيار compute حسب التحكم وعبء التشغيل.

Storage

S3 · EBS · EFS · Backup · Storage Gateway
Object vs block vs shared file; lifecycle and restore time matter.

Object / block / shared file.

Network

VPC · SG · NACL · Route 53 · VPN · Direct Connect
Private-by-default, least-privilege flows, tested hybrid connectivity.

شبكة خاصة واتصال هجين مختبر.

Database

RDS · Aurora · DynamoDB · ElastiCache
Managed DB where fit; Multi-AZ is availability, read replicas are not the same.

Managed DB مع فهم HA.

Integration

SQS · SNS · EventBridge · API Gateway
Decouple, fan-out and route events; build retry/idempotency into business flows.

Queue / fan-out / event routing.

Migration

AWS Transform MGN · DMS · DataSync
Assess dependencies, pilot, cutover, rollback, reconcile.

Migration مع pilot وrollback.

Analytics

Athena · Glue · Kinesis · Redshift · QuickSight
Choose by query, ETL, stream, warehouse and visualization need.

تحليل حسب نوع البيانات.

Operations

CloudWatch · CloudTrail · Config · Systems Manager
Metrics/logs, audit, configuration and fleet operations are different controls.

تشغيل + audit + config + patching.

IaC / DevOps

CloudFormation · CodeBuild · CodePipeline · X-Ray
Repeatable infrastructure and deployment; do not over-focus on developer tooling for this manager role.

2. Architecture that matches the WaCA role

Manager lens: the strongest answer is not “put it on AWS.” It is “make the field workflow resilient to connectivity loss, keep transactions idempotent, and prove recovery.”

4. Current-state corrections

CloudWatch Events

Use Amazon EventBridge terminology for new designs. AWS states EventBridge is the evolution of CloudWatch Events and new features go to EventBridge.

Server Migration Service

The notebook references AWS SMS. AWS sunset that migration path; the current rehosting service is AWS Transform MGN, formerly Application Migration Service.

AWS Data Pipeline

AWS closed new-customer access in July 2024. For new designs, consider current orchestration/ETL options such as AWS Glue, Step Functions or managed workflows based on the use case.

Snow Family

Your notes are useful conceptually for offline/edge transfer, but service availability is changing in 2026. In interviews, focus on the offline-transfer requirement and verify the currently available option before proposing it.
