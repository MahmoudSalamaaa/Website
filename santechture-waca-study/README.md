# SANTECHTURE + MSF WaCA Interview Study Hub

A responsive, joyful interview-preparation workspace for Mahmoud Salama.

## Features

- 39 interview questions across two focused tracks
- Flash-card and full-list study modes
- Search and track/status filters
- Shuffle, confidence marking, and hard-question review
- Local progress persistence
- Keyboard shortcuts and responsive mobile layout

## Run locally

Serve the `dist` folder with any static web server.

## GitHub Pages

Publish the `dist` directory with GitHub Pages or copy its contents to the selected Pages branch.
