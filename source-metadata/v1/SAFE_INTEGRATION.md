# SAFE INTEGRATION — Executive Career Platform v1

This package is **additive only**. It does not replace or delete any existing website file.

## Safest deployment
1. Copy the `executive-lab/` folder into the root of the existing `Website` repository.
2. Commit only that new folder first.
3. Deploy and test `/executive-lab/`.
4. Only after validation, optionally add a single link from the main website/recruiter page and add public lab pages to `sitemap.xml`.

## Do NOT
- do not replace the repository root with this package
- do not delete existing `organizations/data` files
- do not force-push history for this feature
- do not publish private reference contacts or unapproved testimonial quotes

## Public vs private
Public/indexable: hub, role proof, industry pages, readiness, ROI, architecture lab, digital-government lab, skills graph, experience evidence search, playbook, endorsements.
Private/noindex: JD evidence matrix, 90-day plan, content factory, market intelligence, briefing generator, GitHub profile kit.
