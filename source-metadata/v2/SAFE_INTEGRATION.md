# Safe integration

This package is **additive only**.

1. Copy the `executive-lab-v2/` folder to the Website repository root.
2. Do not replace `index.html`, `vercel.json`, `assets/`, `organizations/`, `waca/`, or `.git`.
3. Commit only the new folder first.
4. Deploy and test `/executive-lab-v2/`.
5. Only after validation, add an optional link from the main site or v1 lab.

Private working modules are `noindex` by default. Public thought-leadership/demo pages explicitly opt into indexing.
