# Mahmoud Salama — Wave 4 ADDITIVE

## Safe installation
Copy only the `executive-capital/` folder into the root of the existing Website repository.

This package intentionally does **not** contain or replace:
- root `index.html`
- root `site-main.css`
- root `card.html`

The new entry point is `/executive-capital/`.

Wave 4 is designed to sit alongside Wave 1 (`executive-lab/`), Wave 2 (`executive-lab-v2/`) and Wave 3 (`brand-platform/`).
