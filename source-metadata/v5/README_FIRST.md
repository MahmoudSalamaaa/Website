# Mahmoud Salama — Wave 5 Executive Growth & Opportunity Engine

## Safe installation
Copy only the `executive-growth/` folder into the root of the existing Website repository.

Wave 5 intentionally does **not** contain or replace:
- root `index.html`
- root `site-main.css`
- root `card.html`

Entry point: `/executive-growth/`

### Public / indexable modules
- `/executive-growth/advisory/`
- `/executive-growth/public-profile/`
- `/executive-growth/leadership-simulator/`

All operating trackers are `noindex` by default. Tracker data is stored in the local browser unless exported manually.
