# Safe Integration

1. Add `executive-growth/` as a new folder.
2. Do not replace the site root.
3. Do not modify `card.html`.
4. Do not merge Wave 5 CSS into `site-main.css`; keep `wave5.css` isolated.
5. Review public modules before adding them to the sitemap.
6. Keep operational modules noindex.
7. If linking from the homepage later, add one small reviewed CTA only; do not add a new visual system to the homepage.
